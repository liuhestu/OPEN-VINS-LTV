## 3. 冻结的六次实验矩阵

全部无传感器噪声、使用旧场景、旧零均值初值和旧外参。离散输入为原 200 Hz IMU / 20 Hz camera，保持原输入采样及首帧语义。

| ID | 场景 | 实现 | 参数 | ID 寿命 | 总时长 | 唯一主要目的 |
|---|---|---|---|---|---:|---|
| E1 | S_PAPER | SPLIT_REF | C0 | 固定 | 20 s | 补齐 CONT / SPLIT / CORE，区分两类离散差异 |
| E2 | S_PAPER | 真实 CORE | C0 | 固定 | 30 s | 检查严档速度后续是否保持；不修改5秒验证要求 |
| E3 | REGULAR | 原已验证离散目标 | C2 | 1 s | 60 s | 更强 bearing 增益能否改善短寿命，而非只看C6 |
| E4 | FAST | 同上 | C2 | 1 s | 60 s | 在另一既有几何上验证同一增益干预 |
| E5 | S_PAPER | 原已验证离散目标 | C0 | 1 s | 20 s | 强激励场景中，仅身份中断是否仍破坏估计 |

这里“原已验证离散目标”是 v2 的 EXPERIMENTAL 数值同构副本，所有初始化 hook 关闭；也可直接用真实 CORE，但必须保持现有物理行为和已验证的身份一致。不得趁机换积分器、修改状态重建或谱保护。

## 4. E1–E2：把连续与离散问题收尾

### E1：S_PAPER 高精度分步参考

复用已验证的 SPLIT_REF，保持和原 CORE 一样的 IMU 区间、相机时刻及冻结 C/y 的语义。继续使用已有精确/高精度子流，不另写未经验证的简化参考。

在 0–20 s、完全相同物理采样时刻分别比较：

- CORE − SPLIT_REF：数值子流、保护和事件实现的差别；
- SPLIT_REF − CONT_REF：采样、观测冻结和分步组织的差别；
- CORE − CONT_REF：总差别。

输出 v、eta、路标的分量/范数误差，P 相对差，以及宽/严档达标时间。不能用一种混合物理单位的 state norm 取代所有指标。

SPLIT_REF 的适用 API 或事件语义若必须调整，应先做短小公式/映射测试。遇到需要额外完整参考精度复算的阻断时，必须计入剩余6次并列明被挤出的后续项，不得无预算增加运行。

### E2：同一个 CORE 试验延长至30秒

从与原20秒试验相同的 t=0 启动，保存0–30秒；先逐值核对0–20秒的输入、状态、ID/slot和所有可比较的P快照与原结果一致。

不得只从20秒拼接一段缺少内部P、游标或生命周期状态的重新初始化轨迹。只有精确完整checkpoint才能等价续跑；本方案默认从头运行。

按原规则重新计算“进入目标并保持至结束，剩余验证至少5秒”。不把阈值改成4.795秒，也不预设后续一定达标。

相机校正前/后都要检查。增加时长后可能出现新的越界；照实记录。旧20秒的“未观察到满足完整验收”保持不变，30秒结论另列。

如果新段仍未满足，输出 `NOT_OBSERVED_WITHIN_30S`；不要继续延长到获得理想结果。本次也不要求重新运行30秒 CONT_REF：0–20秒用于连续/离散比较，20–30秒仅用于生产核心持续性检查，不假装拥有新段连续参考。

## 5. E3–E4：评价增益的权衡，不追溯改变C6

旧结论应同时保留：C6按原硬规则被选中；C2/C4对J_tail的改善更大，但有一项小的连续eta退化。不能写成“此前只验证过C6”或“K怎么调都无效”。

先离线提取已有 C0/C2/C4/C6 固定点结果，用同一旧指标列出收益与代价，包括原约7e-6 m/s²的重力误差增加。数值可分辨不等于工程上必然重要，但不得因此篡改原选参规则。

本次 E3/E4 的身份固定为 `EXPLORATORY_GAIN_TRADEOFF`，不再举行候选评选。比较各自相同场景、1秒寿命、零初值下的已有 C0 和 C6：

- 全过程及原50–60秒的 v、eta、路标误差；
- 同一宽/严目标内的时间比例；
- 观测结束前路标达标率与 v-g-路标联合达标率；
- 启动及每次换点后的峰值、波动持续时间、正距离比例；
- 相机子步、实际校正贡献和运行成本。

不需要所有指标同时下降才能“完成该对照”；但数值错误、NaN或失稳仍是失败。允许结论为“速度更好、重力略差”“噪声与部署未验证”或“更强Q也不能恢复短寿命估计”。

没有新增 C2 噪声验证，也没有 S_PAPER C2 固定点对照：不得宣称已得到最终通用参数。任何正向结果都只在本次条件范围内成立，不自动写回生产配置。

## 6. E5–E6：把短寿命条件带到较强激励场景

使用旧 S_PAPER 完全相同的物理点、运动、IMU、bearing、参数、初始化和离散方式，只把 measurement ID 按旧轮换公式设为1秒或5秒寿命。

稳定ID对照直接复用原 `11_PAPER_CORE_C0` 的0–20秒输出；它已有相同物理输入，不因E2是30秒而混用不同评价区间。

模拟器内部的 physical_id 只用于配对和评价，不能交给 observer 恢复旧点身份或均值。

必须沿用原 S_PAPER 实际 `max_features`、`min_features`、漏检保留和warmup配置；不能为该测试偷偷换成REGULAR配置。若有未观测旧ID短暂占槽，记录实际活动数、当前观测数、延迟入槽及状态维度。所有P交叉块按原规则处理。

沿用有符号理想单位bearing，不用 camera/camera.z() 在过零时制造奇异值，不翻轴、不新增FOV裁剪。S_PAPER本就不是全程物理可见相机模型，本次只隔离理想模型里的身份连续性。

输出同一几何、同一时域下的三列：固定ID / 1s ID / 5s ID。全局v/g误差保留完整时轴；逐点指标保留入槽年龄、最后可见时间、右删失及未入槽数量。不要因有效输出减少只比较各自最有利样本。

若较强激励仍不能救回短ID，支持“当前短历史/初始化限制不只出现在弱激励REGULAR”；若明显救回，则必须给出对应几何与寿命条件，不能声称真实短轨迹已验证。

工具正确性验收不放宽；运行结果负面不自动阻断其余数学可信的实验。只对G/V输出质量作结论，不计算odom ATE，不把有符号bearing理想结果外推为现实可见性保证。

| 问题 | 需要的结论 |
|---|---|
| 连续参考 | 哪些既定场景能够达标，时间多长，是否具有明显场景依赖？ |
