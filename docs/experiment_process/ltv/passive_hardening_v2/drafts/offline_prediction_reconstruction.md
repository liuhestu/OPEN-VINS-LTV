# Offline signed correction and per-point prediction evidence

The complete R3B V2_03 cache permits an input/state-only reconstruction without replaying the observer. The dedicated tools are `diagnostics/export_prediction_cache.cpp`, `diagnostics/reconstruct_prediction.py` and `diagnostics/test_prediction_math.py`. Original cache tools and tested estimator sources remain unchanged.

At each camera event, reconstruction starts from the **actual preceding cached post-correction state**, not a separately evolved observer. Raw IMU events retain their original arrival order and shared left/right boundary. Interpolation uses the Adapter's cursor and current target; accelerometer/gyro calibration, current biases, gyro acceleration sensitivity and per-interval endpoint averaging follow `LtvAdapter::correct` and `processHardened`. The core's explicit old-state Euler mean equation is reproduced with the same dense system/input structure. The complete P is parsed as part of the existing cache serialization but is neither propagated nor used. Gain, camera correction, manager admission and seed decisions are never recomputed.

The camera's actual managed cam0 observations and preceding physical-ID/slot map determine angular diagnostics. Only previously existing slots with finite predicted ray length at least0.1m enter the original P95. Newborn means come from the actual cached seed/zero-mean choice after lifecycle processing, and cannot retroactively enter that pre-lifecycle P95. The angular vector residual is the predicted body ray unit vector minus the measured bearing transformed by current R_BC. P95 uses sorted angles at `ceil(.95*N)-1`. Signed Δv and Δη equal actual current cache post-state minus reconstructed predicted state. Their scalar norms use the actual last-correction time difference, including thin updates; this is not the time since the last valid/ready output.

Reconstruction validates exact receipt time, epoch, sequence, availability, camera substeps and raw v/eta agreement between cache and original features.jsonl. Its scalar absolute tolerance was fixed to1e-9 before candidate execution. Validity must exactly match the actual logged diagnostic-valid flag. Pause, first-state, epoch and cold/Dormant exclusions are explicit; unsupported transitions cannot be silently joined. This current evidence contains one observer epoch and no later reset/cold transition, so those branches are not claimed experimentally covered.

These records distinguish persistent angular mismatch from the direction/magnitude of accumulated correction. The exported predicted quantities are actual pre-camera correction estimates, not ground truth and not a new scientific convergence result.
