# R3C 因果窗口候选独立审查

审查对象为补齐 `Exact state and boundary contract before registration` 后的 `r3c_causal_window_proposal.md`。本审查只读提案、现有证据与轮次合同，没有实现、生成假想 ready mask、调整参数或运行实验。

**结论：当前数学与状态合同足够登记为 R3 内第三个 availability 候选，再进入实现和小反例验收。不是科学验收通过，也不是纯工具修复。** 最初版本关于窗口填充、失败后是否清历史、角区间与校正原子、分支隔离和容量的阻断，已由新增合同明确解决。登记仍须由主线程核对实际候选账本和最终验收剩余预算。

## 证据与轮次边界

282 修正后的两个事前固定窗口支持“瞬时校正速率可能大而累计方向相抵”的可检验假设。278/285 同时显示：这两窗内高角点多数是少数点，但全域存在多数点同时异常的包；部分大共享校正没有高角点。因此不能把单点异常当成唯一原因，也不能从相抵推导估计准确。280 使用错误时间原点的分窗结果不参与本次论证。

276/277/284 支持已发生校正的因果传输描述，signed Δ 仍是按旧值公式重构并经范数交叉核对，不能冒充独立 live 方向 oracle。出生前均值及 unit-ray 残差的既有解释限制继续保留。新实现应直接取得实际校正前后共享状态，不把离线重构器作为在线必需组件。

goal 第 3.2 节允许 readiness 与恢复确认修改；protocol 规定最多三机制轮、每轮四候选。该方案改变 R3 内 availability 的观测统计，不改变 observer/seed/gain 或再启一套滤波器，可计为第三候选。它不是延长 R3B grace、扫描倍数或把失败结果重新标成功。固定一次 1 s、活动倍率 2、增量上界后不按开发结果扫窗或调限；新行为必须单独登记，旧 R3B 的 joint 2.85 s、NOT_MET 不变。

倍率 2 和增量上界是新的固定设计选择；虽然单位可由原速率乘 1 s 得到，但它们允许原检查拒绝的瞬时变化，不能继承原策略安全性。开发 V2_03 证据不构成独立泛化证据。

## 数学与时序复核

对历史校正 δ_j，当前贡献为 c_j(t)=Φ(t,t_j)δ_j；Φ 使用实际执行的旧值 Euler 子步按时间左乘，包含 η→v。净量是 `norm(sum(c_j))/1s`，活动量是 `sum(norm(c_j))/1s`，分别取 v 或 η 的三维块；原子上界使用原始 δ_j 的对应块，不能误用传输后最大值或混合六维范数。v 与 η 的速率单位分别是 m/s² 与 m/s³。

校正是事件原子，仅在 `t-1 < t_j <= t` 纳入，不按边界交叠比例缩放。角统计采用实际右端点 P95 对前一物理区间的加权，并裁剪左右边界；这是明确的离散样本统计，不是连续真实 bearing 的积分，也不是 pooled P95。首 hard-valid anchor 前权重为零，完整性不能靠权重求和容差补真实缺口。

窗口满 1 s 之前只填充、不计确认，也不能因未满而每帧清空。完整且预算通过的第一帧才计确认 1，第 20 帧 ready。采用记录的物理 IMU target、严格 `target-anchor >= 1.0`，不把相机时间或离线绘图端点容差混入。合法稀疏相机间隔与离线科学 episode 连续性规则分别保留；在线有效窗口不自动证明离线连续 5 s。

普通净量、活动量、平均角度和原始增量预算失败撤回相关 ready、清确认，但保留真实历史及不利样本；这避免主动清掉异常而降低下帧预算。G 预算失败同时使 V 失败，V 独有失败不清 G。共享 hard 故障、current P95 外界失败等才清共同历史与两个确认计数。无需重复 R3B grace 状态。

过期项先删除，跨左界的角区间由其右端事件自持；需要第 65 项时显式 hard reject，不丢必需样本后声称完整。epoch、previous cursor、current target 与实际 Φ 必须一致。重复/非递增输入不得改变内部证据或确认；返回副本仍须明确 rejected、ready false，不能再出现沿用旧健康输出的问题。

## 实现后必须通过的判别反例

- 非交换 Φ 顺序、η→v、不同 body 坐标旋转；直接 affine 状态差与传输一致。不得额外推进均值/P 或重新准入。
- 左界原子恰好过期、角区间部分裁剪、首 anchor 无前向补历史；非零相机/IMU offset、大 epoch、严格 1 s 边界和不规则合法 cadence。
- 同方向大校正触发净量；抵消大校正仍触发活动或原始增量。软失败后 offending sample 必须持续保留到物理过期。
- 完整窗口前零确认、之后恰好 20 帧；共享 hard fault 后重新完整窗口再确认；V 失败不消耗 G，G 失败同时撤 V。
- duplicate、非有限/缺失 transition、epoch/bootstrap 与 acknowledgement 不重复计样本；硬故障后的区间不能跨接。
- 恰好 64 项、先删过期再插入、真正需要 65 项时明确拒绝与有界恢复，不能静默压缩时间支持。
- 默认 OFF 完整 x/P/slots/事件/cache 等价；开启时原始标量仍来自同一真实校正，日志开关数值一致；新增统计和原因可逐帧审计。

这些是实现验收要求，不是已完成测试声明。小测试通过才开展固定开发比较；即使开发 coverage 增加，也必须保留全部 held/ready 支持上的 raw、严重误差、启动、恢复与负对照，沿用原精度/覆盖/连续性门槛。不存在仅凭当前净校正证据即可认可 ready 的结论。
