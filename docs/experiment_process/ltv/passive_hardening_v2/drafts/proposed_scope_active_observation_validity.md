# 待授权范围：活动点的持续观测一致性

**这是新第四主要机制的范围提案，不是现有授权、R3 bugfix或已登记候选。** [goal.md §4](../goal.md)规定：“最多3轮机制级开发，每轮最多4个有记录的候选（总计≤12）”。R3剩余一个位置不能授权第四机制；须用户明确扩展轮次与预算用途后才实施、登记或运行。

**现有依据及限制。** [306结果](past_fit_current_holdout_results.md)与[独立审查](past_fit_holdout_independent_review.md)显示：27537过去11条同ID射线在当前同版本位姿模型下自洽，但与当前射线相差约0.35 rad；29636过去集合本身已不自洽。桥接默认 `match_valid=true` 只表示前端提供该条目，并非独立几何验收。当前没有证据证明已有false标志被错误覆盖，也不能唯一归因为错配。实际贡献分解支持检查观测对共享修正的作用，但没有证明删除某点有益。

**拟请求授权的范围。** 在LTV侧为已活动点提供持续、因果的观测一致性诊断，独立于一次seed是否成功：使用同epoch/ID的过去bearing与当前一份一致版本的只读clone位姿/标定，过去拟合排除当前观测，报告历史自洽程度、当前held-out角、基线/秩、实际支持跨度与缺失克隆。缺支持明确UNAVAILABLE。此处“独立于seed”是职责分离；主VIO位姿与图像相关，不能声称统计独立、GT或已标定失败概率。

保持主OpenVINS前端、状态/P/FEJ、传播及视觉更新不变；G/V注入始终零。保留LTV连续模型与Q/V/P规则、一次均值写入合同及现科学误差/覆盖/恢复门槛；不把一致性拟合点写回作为反复初始化。若未来诊断改变校正观测集合或活动身份，必须明确记为新观测选择机制，不能声称原离散数值保持不变。

**建议一次授权第四轮，内部按证据自动推进。** 首先只实现有界、默认OFF的只读信号及fixture；在预登记的完整局部邻域和正常对照中检查因果、版本、非零杆臂、弱视差、缺克隆、动态/不一致观测及算力。然后固定一个能区分假设的局部干预：从完全相同校正前x/P输入出发，对诊断指明的观测暂不参与该帧更新，完整重算全部子步和P，保留正常执行对照与所有失败。不复用实际路径逐点贡献冒充删除反事实，不以GT挑删点或调在线门限。

只有局部证据支持才冻结少量在线候选并运行完整开发cache，无需再次逐阶段请求用户批准。建议本新增开发轮上限 **2个候选、4次完整真实/cache、8次完整合成、2次短段真实**，全部使用原有总预算余额，不增加80/72/24/30000/12上限；失败和重试均计数，不做组合/门限扫描。完整缓存重演计real；≤10 s真实链路计short_real；仅保存快照上的局部算子代数诊断记analysis，几何重求解逐次计geometry。继续保留至少24合成/40真实最终验收储备。截至307用量20合成/7真实/12短段/2几何/5候选，新增轮上限与储备相容。开发输入已见，不冒称未见确认。以上仍是待授权范围，不能现在消费；最终确认沿原合同与原总预算执行，不自动增加第五轮。

**尚未固定的工程界限。** 需事前明确实际历史/克隆支持不足的处理、静态点模型不成立与位姿误差不可辨识时的处置、只跳当前观测还是永久退出及恢复条件、once-per-ID保护、同时拒绝过多点时的状态/readiness行为、计算频率与内存上限。还需确定诊断是否需要传播完整相关位姿不确定度及其可验证解释。当前两点结果不足以冻结通用阈值，不能直接采用0.35 rad作为门槛；这些待定项不构成现在搜索参数的许可。

最终仍须原完整raw/ready/joint、严重误ready、种子与生命周期、恢复、资源、主VIO精确旁路和未见确认合同全部通过。局部误差改善、新增诊断有效或某两帧被拒绝均不能代替验收。若新信号缺支持或干预无收益，保留负结果并停止该分支，不自动扩为第五机制。
