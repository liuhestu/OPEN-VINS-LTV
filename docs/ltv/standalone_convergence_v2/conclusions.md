## 1. 误差主要来自哪里？

REGULAR 固定 ID 的主要问题是连续慢收敛。C0 的 50–60 s 速度 RMSE：CONT_REF **0.309909**、SPLIT_REF **0.310107**、CORE **0.299691 m/s**。连续参考延长至 120 s 后，宽档联合速度/重力达标时间为 **85.975 s**，严档为 **97.605 s**；全部路标分别为 87.400 / 109.135 s，110–120 s 速度 RMSE 为 **0.021272 m/s**。这支持慢收敛，不能把 60 s 未达标解释为不可收敛平台。

离散误差存在，但不足以解释上述误差：REGULAR 全程 CORE−SPLIT_REF 的速度差 RMSE 为 0.022680 m/s，SPLIT_REF−CONT_REF 为 0.024218 m/s。准确全状态初值下，10 s 连续速度 RMSE 约 1.17e−14，离散副本约 0.00610 m/s。提高 IMU/相机采样率未消除约 0.3 m/s 的末段误差；提高 IMU 频率反而使结果更接近连续参考，说明“离散结果更小”本身不能证明数值更准确。实验副本的实际谱下限抬升计数均为零；这不等于核心没有执行谱检查/重构。

激励差异很大：FAST 连续宽档 t_VG 为 40.775 s，PAPER 为 11.450 s。STATIC 虽可使 v/η 误差极小，路标末段三维 RMSE 仍为 **18.819 m**、负 ray 比例 100%，同时投影残差约 1.22e−15 m。低投影残差不是正确距离的证据。有限窗口几何指标只作诊断，不证明全时间 PE；PAPER 约 49.63% 的真实相机 Z 为负，保留有符号全向模型，不能据此宣称真实相机可见性成立。

## 2. Q、V、P(0) 的收益与代价是什么？

冻结规则选出 **C6：Q=1e−4、各 V=1e6、各初始 P=10000**。REGULAR 离散 J_tail 从 3.887686 降到 3.872753，约 **0.384%**；60 s 内仍未获得宽档联合收敛。C2/C4 的 J_tail 改善更大，但连续 η RMSE 有约 7e−6 m/s² 的可分辨退化，按逐指标非退化合同排除，没有事后加入百分比容忍带。C6 是诊断选择，不是推荐生产参数。

C6 固定点速度瞬态峰值略降，未出现允许但需披露的峰值增加；C1 则显著增加瞬态峰值及大误差持续时间。全部候选的峰值、超过 C0 峰值的持续时间、全过程误差与真实校正量保留在报告和证据中。FAST 的 C6 离散宽档收敛时间与 C0 在 0.005 s 分辨率下相同，末段速度改善约 1.5e−6 m/s，不能称为明显加速。

两个冻结联合传感器噪声种子下，C0 末段速度 RMSE 从无噪的 0.300 增至 **0.929–0.937 m/s**；C6 每种子仅减少约 **0.0003 m/s**。这是很小的可分辨收益，没有解决噪声敏感性。本轮未做 IMU/bearing 噪声分通道消融，不能将代价单独归因于某一通道；两个种子也不足以作统计可靠性保证。

## 3. 增益收益能否延续到短寿命？

没有获得短寿命可靠估计。C0 在 REGULAR/FAST、0.5/1/2/5 s 四档寿命下，已结束观测轨迹的消失前路标宽档成功率均为 **0%**。1 s 寿命的 REGULAR 高精度 SPLIT_REF 也为 0%，末段速度 RMSE 1.541 m/s，接近离散 C0 的 1.533 m/s，支持生命周期与初值问题主导，而不是 Euler 子流误差制造了失败。

1 s 寿命下 C6 的 REGULAR 速度 RMSE 仅由 1.533456 降至 1.532480 m/s；FAST 从 4.706847 升至 4.710399 m/s。不能把固定 ID 的微小收益外推为换点收益。换点后反复出现的波动保留完整时间轴，并按每次出生后的 0.2 s 窗口与 C0 配对统计；窗口可能重叠，计数不是独立试验，也不是因果证明。10 s 后出生窗口中，REGULAR 有 466/1001、FAST 有 584/1001 个窗口的 C6 速度峰值高于 C0；FAST 的后段公共采样峰值从 6.642127 升至 6.656316 m/s，超过 C0 后段峰值共约 0.020 s。退化并非只在启动出现，但也没有超过 C0 的全程峰值。详见 `evidence/repeated_transients.json`。

## 4. 一次几何初始化有帮助吗？

有明显帮助，但依赖种子质量及额外位姿先验。全部初始化固定 C0、1 s 寿命，不改变 v/η 的均值或 P 规则。REGULAR 的末段速度 RMSE：零种子 **1.533456**、GT_SEED **0.006827**、GEOM_IDEAL **0.042913**、GT_MATCHED **0.042913**、GEOM_NOISY **0.371293 m/s**；FAST 分别为 **4.706847、0.014010、0.013753、0.013753、0.415236 m/s**。

GEOM_IDEAL 与 GT_MATCHED 的成功点及触发时刻完全相同，误差结果接近浮点精度，说明理想几何三角化可重现同等待时间的真值种子。GT_SEED 在入槽时写入，几何种子至少等待三帧及 0.10 s，并需视差、条件数、残差和正射线门限。等待期间仍保留零初始化误差，不删掉启动或换点后的区间。REGULAR 理想几何种子末段路标总体 RMSE 仍为 **3.015 m**，尽管相对误差 P95 约 0.175%；少量等待中的大误差不能被成功率或分位数掩盖。

GEOM_NOISY 使用位置标准差 0.01 m、姿态标准差 0.1° 的额外位姿先验，三角化及执行时的坐标变换都使用带噪先验。它改善零种子结果，但远未达到理想种子的质量；不能把“几何种子有效”解释为已具备可靠在线初始化。这里传感器输入为无噪，噪声只加于几何位姿先验；没有验证传感器噪声与先验噪声叠加的场景。逐点消失前成功率、联合达标率、等待及接受率见下表和报告表 5。

## 5. 下一项有证据支持的最小修改

优先在独立副本验证**依据位姿先验误差与三角化深度不确定度，拒绝不可靠的一次几何种子**，同时保留被拒绝点的等待时间、成功率及全过程误差。这是后续研究建议，本轮没有追加候选或实施该门限。依据是：理想几何与匹配真值几乎一致，而带噪位姿下较高接受数量没有换来相应的可靠估计；仅扩大 P0 的收益小且不能挽救短寿命。

该后续验证应先固定当前运动、C0、寿命和噪声，单独改变种子质量判断，不同时调增益或协方差，不以接受率提升替代消失前联合达标。当前 hook 保留 P 是本轮对照要求，并不意味着该 P 已包含额外位姿先验的统计不确定性。
