## 离散化：两类误差及持续性边界

三场景原时域内的速度差RMSE，CORE−SPLIT / SPLIT−CONT分别为：REGULAR **0.022680 / 0.024218 m/s**，FAST **0.034246 / 0.030922 m/s**，PAPER **0.053074 / 0.038964 m/s**。精确数值、η/路标分量及P差见[比较证据](evidence/comparisons.json)。这些RMSE不是可相加的独立误差预算，也不能直接比较不同场景的相对重要性而忽略真值尺度。

PAPER的CORE−SPLIT与SPLIT−CONT整秒完整P相对差最大值分别为 **0.031487 / 0.041512**。前者隔离子流数值、保护及实现差别，后者包含采样、bearing冻结与分步组织。本轮没有修改任何算法来减小它们，也没有30 s的连续或分步参考。

E2与旧CORE的0–20 s实际输入、完整状态、slot及可比P快照逐值一致。20 s后第一次严档速度越界为 **21.900 s**，最后为 **28.750 s**，该段含相机两侧的最大误差 **0.054698 m/s**。从28.755 s持续合格至30 s仅余 **1.245 s**。因此旧20 s的不足验证时间不是唯一问题，延长后出现了新的越界；宽档仍保持通过。20–30 s速度RMSE为0.039757 m/s，200 Hz严档VG目标内时间比例约94.60%，不能替代“之后始终满足并至少5 s”的严格定义。详见[逐次越界](evidence/E2_new_violations.csv)。不继续延长，不把残余波动无证据地全归因于某一种子流。

本轮未验证C2噪声或PAPER固定点泛化，不给生产参数建议。对本次两场景1 s寿命，“提高Q有局部收益”与“仍不满足可靠估计目标”同时成立。

## 研究取舍与唯一下一项建议

本阶段证据已足以停止继续扩大增益搜索，也不足以支持将当前零初始化短寿命方案接回生产闭环。连续第一层在既定激励下可收敛，离散严档残差和生命周期问题需要分开对待。

**唯一建议：单独做一次几何种子沿射线不确定度的离线校准验证**——用已知位姿先验误差评估三角化预测不确定度，与现有种子深度误差及覆盖率对照；暂不改变种子均值、准入门限或P。该建议由“很小横向残差与数米沿ray误差并存”直接支持，但其有效性尚未验证。本轮不执行该建议，不实现Gate，不开展新搜索或OpenVINS闭环。
