# Geometry module contract (draft for main-agent review)

The deployable module accepts only caller-provided observations, pose means and joint uncertainty; it has no truth/data-loader access. R_WB and R_BC map body→world and camera→body. Camera position p_BC is expressed in body. Seed output is R_WB(s)^T(f_W-p_WB(s)), at the actual execution pose. Current stereo cameras share one pose index; temporal observations refer to unique pose indices from one coherent context version.

The point-line solution is A f = sum H c, H=I-ddᵀ. A is geometry, not a covariance or the Riccati matrix. Quality policy remains outside the numerical module. Degenerate A, nonpositive signed ray, invalid rotation, future pose or nonfinite input is rejected. Negative optical Z is not automatically rejected: signed bearing and forward ray are distinct concepts.

For every unique pose the perturbation is [right rotation δθ_B, additive world δp_W]; for every extrinsic it is [right rotation δθ_C, additive body δp_BC]; every unit bearing uses a deterministic orthonormal two-column tangent basis. Column ordering is all poses, all cameras, all bearings. Uncertainty accepts the complete joint Sigma_u in this ordering, including cross-frame and pose/bearing cross blocks when available. A repeated execution pose is not duplicated. Exact fixed calibration uses zero rows and columns. PSD singular matrices are accepted; no diagonal jitter or gauge removal is applied.

Differentiating A f = b gives δf=A⁻¹ sum[H δc + ((dᵀ(f-c))I+d(f-c)ᵀ) δd]. Execution-pose rotation and translation are then differentiated in the same Jacobian. Sigma_ell=J Sigma_u Jᵀ. sigma_parallel uses the nominal frozen anchor ray expressed at execution time. This is a local directional risk, **not a calibrated 95% interval or full distance uncertainty**. Camera-ray-direction uncertainty in a claimed range variable would require its own composite derivative. P_E is read-only; P_L is unchanged; Sigma_seed only informs admission.

Real VIO may not expose state–measurement cross covariance. Such missing correlation must be labelled an approximation; independent diagonal per-clone matrices cannot be called complete joint uncertainty. Current stereo geometry cancels common body pose exactly and provides a simpler source, but uses right-camera information beyond old monocular LTV and still has measurement/calibration uncertainties.

Short authored tests cover nonidentity rotation/nonzero lever arm, current stereo/temporal observations, gauge invariance, analytic composite Jacobian at two finite-difference steps (absolute 2e-5, fixed before execution), PSD gauge covariance, indefinite covariance, identical-ray degeneracy, causal timestamp rejection and range/Z distinction.
