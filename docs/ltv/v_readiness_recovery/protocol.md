# V-only 20/10 帧确认敏感性：预先冻结合同

从 f22bfbcd82fe9a2b82d85ce9079fcd33d496e3f8 创建 feature/ltv-v-readiness-recovery。唯一算法变化为实验 runner 的 V10 模式：V strict-good 确认由20改10，生产默认和 G 确认仍20。不暴露生产 YAML 开关。不改变成熟/观测15、有效修正20、prediction angle、correction rate、gravity norm、时间/初始化/FEJ、grace、噪声或NIS。无GT在线输入。

固定上一轮 C02 的全部输入和配置哈希、单线程、最多两个计算进程。矩阵仅四次完整真实回放：V2_02/V2_03 各 V20 重放一次，精确匹配既有 V-only；通过后各 V10 一次。任何失败计入既有账本，明确实现阻断修复只允许必要复验；不得扫描确认长度或融合权重。原 real 开始计数66，四次计划至70，原工程预算上限71。

GT、时间、坐标和共同支持沿用 f22bfbc 的物理 body 参考及16f02e3冻结 ATE/RPE。常规轨迹对齐使用全程共同支持的同一个 SE(3)无尺度拟合，再对子区间切分，不单独拟合恢复段；GT最近邻20ms、输出匹配1us。body速度 GT 用物理时间插值、SLERP、间隙≤10ms；与轨迹指标参考差别明确列出。

区间从既有 V20 冻结，不依据 V10 或GT放行：首次V20 ready之前为启动；之后的每次V20 not-ready期间及其返回ready后1s为恢复段，其余为正常段。长中断及未恢复的尾段不删除。各恢复episode以V20 ready→not-ready首帧为共同锚点，对比首次V10和V20再ready时间；若V10在锚点已经ready，报告0等待及持续ready，而不当作新确认。未恢复episode保留右删失。另列V20一直未恢复但V10独立放行的区间，以及转换数/ready短段（<1s）数。首次启动与恢复分开。

新增实际更新严格按 consumed、V_rows=3、joint_applied、ekf_calls=1，与V20同时间事件比较。报告增加与减少事件、位置、ready/grace、残差/NIS、原始速度误差、相对主冻结先验误差、以及用真实联合增益V列计算的速度/姿态/位置修正量和误差修正方向，三种单位不混合。分支独立注入仅是方向诊断，不是额外在线更新。

质量的预定义评价：误差尾阈值0.1/0.2/1m/s只用于离线计数。新增实际放行与原V20实际放行分布同时报告，还与V20同时间原始LTV输出配对，避免误把困难窗口选择偏差归于长度变化。定义明显恶化为：新增放行速度RMSE超过原V20实际放行的1.25倍且绝对增加>0.01m/s，或P95绝对增加>0.05m/s，或>0.2m/s比例增加>5个百分点；任何非有限状态/原谱边界违反也保留20。这是本次工程选择口径，不是统计一致性证明或新的在线门控。若恢复改善且无上述恶化，记录10帧的实验工程结果；生产默认仍20。ATE/RPE保留原值和失败标记，不把微小变化说成收益。
