## 输入、标定、时间

使用确定性原始文本回放。UZH图像为id timestamp path，IMU数据为id timestamp wx wy wz ax ay az（注释缺id），GT为timestamp xyz qxyzw。十进制转统一整数ns，保留原文；双目只精确时间配对、记录未配对帧；全图像存在/可解码/时序检查；IMU左右包围、禁止外推。

完整输入包括起始静止段，不额外裁剪或GT初始化。t_imu=t_camera+cam0固定时差；预测、LTV、输出及GT均使用物理IMU时刻，记录两个时刻；原生cam0公共时差语义保留，记录cam1差异，不新增双时差状态。现有零时差Python限制不能沿用。

从仓库对应UZH配置派生固定标定、MSCKF-only、在线标定/SLAM/ArUco/ZUPT OFF配置，保留原场景噪声、模型、前端；核对官方标定并在看效果前记录差异与选用依据。同一场景所有模式设置相同。不得宣称代表原版完整配置最优性能。

## 只读诊断与核心问题

记录传播/clone后更新前prior、视觉门控压缩后冻结输入、同一次更新posterior。记录事件epoch/version/snapshot/camera/imu时间，current/FEJ姿态速度bias，LTV G/V/P诊断/有效性/特征/warmup，完整P与视觉/辅助order,H,res,R，实际posterior和拒绝原因、接受视觉规模、分项耗时。大矩阵压缩存储；不能重复推进、claim、消费receipt或实际EKF。

Passive用于主要互补性分析，允许独立临时对象计算候选G/V，不进入滤波。主估计prior机体系速度R_GtoI*v_G，重力R_GtoI*[0,0,-1]；GT对应R_ItoW转置变换速度及世界重力。此比较不套用ATE拟合旋转。必须验证GT参考刚体、杆臂、姿态和世界重力；不确定指标记不可验证。

EuRoC使用GT原速度；UZH位置在查询时刻用总宽0.10s局部三次拟合求导，0.05/0.20s敏感性，真实不等距时间，至少9点，不跨>10ms间隙、不外推。姿态SLERP相邻GT，>10ms间隙无效。明确派生参考速度与GT生成信息来源；窗口改变结论符号时不得据此调权重。

逐序列G角误差/V向量RMSE、中位数/P95、LTV胜出比例、三轴有偏二阶矩/去均值相关、prior误差与LTV-prior方向内积、连续受益受损区间。G在共同参考切平面比较二维方向误差，不能仅相关两个非负角误差。近零方差相关记未定义。块bootstrap 1s,2000次,seed42，不当作独立帧统计或跨场景显著性。

离线同prior/P/实际已接受视觉块计算visual,visual+G,visual+V,visual+GV。使用实际门控和完整P、原生扰动；不重跑跟踪/选特征/推进未来。比较辅助posterior相对visual-only误差，不能把视觉收益归LTV；K_G*r_G仅作分量诊断。单步反事实不等于闭环因果证明。

运动分层：1s陀螺RMS、abs(norm(a)-g) RMS，EuRoC对照/UZH开发各自P75冻结，验证复用。后者称比力变化不是真实平移加速度。B/P接受视觉行数为0单列，非零最低四分位为弱视觉。整体/高旋转/高比力/弱视觉及交集，<5s仅描述不用作门槛；各方法统一B/P标签。报告GT支持和全输入两套运动统计，避免落地冲击峰值误导。

### 条件式权重门槛

初值C0=(sigmaG=10deg,sigmaV=1m/s)，observer/NIS/warmup/quality gate不变。G/V分别在至少2/3 UZH开发序列的整体或同一个预定困难分层满足：
1. LTV RMSE较prior低>=5%，或辅助反事实RMSE较visual-only低>=5%；
2. 对应改善块bootstrap区间支持正收益；
3. 反事实P95误差恶化不超过10%；
4. 速度优势不随求导窗口反转。

候选：C1=(5deg,1)仅G达标；C2=(10deg,0.5)仅V达标；C3=(5deg,0.5)两者达标。无资格保留C0。最多3额外组、仅三UZH开发，不逐序列参数。

候选依次排除数学/数值/时序/新增运行失败、覆盖下降、任一开发序列G/V P95比C0恶化>10%。要求目标分支至少2/3开发改善且三条平均ATE不劣于C0。优先更保守仅增强单分支；同等条件按目标分支相对误差改善排序，ATE仅末级判别。无合格保留C0。一组最终G/V参数覆盖所有序列。

### 评价与复测

无尺度SE3 ATE；补1s/5s RPE、G/V直接误差/反事实、初始化/传感器/GT/辅助覆盖、reset/失败/NaN/counts、observer/辅助/EKF/诊断耗时。GT晚开始不裁传感器；目标时间支持为B初始化后与有效GT交集，冻结所有模式，输出覆盖门槛99%，不缩小交集掩盖失败。

复测三条唯一序列：V1_01、UZH验证GV最大有效收益、UZH验证最大退化（无退化最小改善）。第三名优先复现失败。缺少有效可比结果时按固定验证清单顺序补足，不按最好结果替换首次正式值。
