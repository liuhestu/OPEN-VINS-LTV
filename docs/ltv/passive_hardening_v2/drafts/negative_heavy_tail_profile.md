# Negative bearing profile frozen before confirmation

Only `condition=WRONG_MATCH` combines the existing wrong-ID association with additional heavy-tailed bearing input. Other conditions never call this profile or consume its random generator. The normal 0.05 degree Gaussian bearing noise, pose noise, endpoint IMU arrays, assumed measurement sigma, solver thresholds and observer parameters remain unchanged.

After Gaussian bearings are generated for both cameras, an independent NumPy generator seeded with `SeedSequence([seed,57031])` draws an independent Bernoulli 0.02 flag per camera and physical point on every camera event. It draws three independent Student-t(df=3) components scaled by 0.5 degrees in radians, projects this vector onto the current bearing's tangent plane, adds it to the bearing and normalizes **only flagged bearings**. The scale is the component Student-t scale before tangent projection, not its standard deviation or a fixed angular displacement. Nonflagged values are copied bit for bit. Draws include currently invisible physical points, so visibility and association cannot alter the RNG schedule.

The existing wrong-ID rule then selects the actual `source_slot`; both the emitted bearing and evaluator-only `heavy_tail_outlier` flag use that source slot. Therefore the flag follows the physical ray even when the reported feature ID is wrong. Flags, truth identity and the profile description stay in `labels.npz` / `identity.json`; `inputs.npz` contains only the perturbed bearing and ordinary causal observations. The estimator is not told which observations are outliers.

This is a predeclared negative stress input, not a calibrated probability of estimator failure. It does not alter reliable-supply thresholds or permit outcome-dependent exclusion of points. Previously frozen inputs remain immutable. Input identity records the profile parameters explicitly, and any newly generated negative input has a new input SHA.

Contract tests cover deterministic draws, exact unchanged nonflagged bearings, unit normalization, normal-condition non-invocation, source-slot label mapping and exact reproduction of the frozen development normal input 52 SHA. Generation of that normal file in a temporary test directory does not run an observer or replace historical evidence. Test results belong to the shared execution ledger; this document makes no premature scientific pass claim.
