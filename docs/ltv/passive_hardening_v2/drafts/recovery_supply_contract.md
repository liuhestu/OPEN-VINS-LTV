# 恢复计时的固定输入供给定义

本定义在任何 RECOVERY 完整输入生成前固定，不回填/改写已冻结输入52。它是模型下的输入资格诊断，不是实际种子成功概率，也不保证最终输出正确。不得根据10秒恢复结果调整。

每个当前点必须同时具备：当前两相机真实可见；同一物理点正确匹配；两观测原整数时间等于本包时间；cam0至少3连续帧且跨度≥0.10s。当前相机实际点/位姿真值仅用于离线标签，估计器不读取。

几何门槛预定为最小ray距离0.1m、两真射线夹角≥0.5°、点线正规矩阵condition≤1e8。使用实际固定外参、固定bearing标准差0.05°，在执行机体系中令点到相机的真距离为r_c、单位方向为b_c、Π_c=I-b_cb_cᵀ，定义

```
A = Π_0 + Π_1
C = A⁻¹ [σ_b² (r_0² Π_0 + r_1² Π_1)] A⁻ᵀ
ρ = sqrt(b_0ᵀ C b_0) / r_0
```

要求ρ≤0.05。这是点线最小二乘在真实几何处的独立一阶噪声传播，不调用候选估计器、候选风险函数或候选误差。两相机共享当前pose的旋转/平移在当前机体系相对点中抵消，采用固定外参假设；因此没有将共同pose误差重复加为独立相机误差。不能把这个诊断扩展声称为实际全噪声下置信覆盖。

一个相机时刻有至少15个这样的点才 `sufficient_reliable_supply=true`。`sufficient_reliable_supply_run_start` 给当前连续true段起点，false时为−1。恢复计时使用恢复阶段内这类连续供给段的起点，不直接用脚本30s或可见点数代替。短寿命导致供给中断应如实报告，不能为了计时成功将多个断开的段拼接。Temporal-only场景此标签为false，表示此固定充分条件未建立，不等价于历史几何不可观。

字段只在 `labels.npz`：

- `reliable_supply_feature_ids`: [tick, feature_id]；
- `reliable_supply_count`: 每相机tick的资格点数；
- `sufficient_reliable_supply`: 每相机tick bool；
- `sufficient_reliable_supply_run_start`: 同上，秒。

机会分母与上述更强恢复供给标签保持分离：Stereo机会是当前合法同步两目，Temporal机会是3连续帧/.10s历史，均在最终风险/容量前定义。错误匹配负样本的可观测ID仍进入合法前端机会代理分母，但因真实物理ID不符不能进入可靠供给标签。时间错误观测明确排除同步Stereo机会和供给。

独立小测试包括近距离正常双目、零baseline、远距离、错匹配/异步、历史不足、少于15点。生成器未读取候选输出；确认种子只允许预登记201/202、301/302，且需要本轮freeze SHA。
