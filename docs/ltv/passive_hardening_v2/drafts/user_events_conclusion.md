## 运动、观测与 LTV 的区分

两处存在转动和比力变化，均有10个实际 IMU 子步，已纳入预测。比力不是去重力后的世界加速度；当前证据不证明 IMU 故障或离散化是根因。OpenVINS 同时刻误差小，且同时间校正前后分解直接表明：76.75 s 的恶化发生于 LTV 观测校正，不能全部归因于运动变化。

76.75 s 没有路标出生或删除。23个旧点中 ID27537 预测角残差0.349214 rad，校正后仍0.216458 rad，但 P95 仅0.011555 rad，因为该统计排除了最大值。78.90 s 有5个出生、5个删除，22个旧点中 ID29636 为0.163584→0.091500 rad，P95仅0.005291 rad。小 P95 与个别严重不一致可以共存；点残差降低也不保证共享速度变好。

这些是观测与状态不一致的证据，尚不能区分错误匹配、路标估计误差、先验误差各自贡献，也不能证明单个点造成共享校正。没有据此删除点、实现种子 Gate 或调增益。逐点因果分解还需实际校正算子、完整交叉协方差及更新顺序。

后续 analysis297 补齐了实际校正算子的加法分解：两个固定邻域42帧各自从缓存前一后验完整 x/P 起算，重建实际 IMU 子步、生命周期及所有相机校正子步。最大归一化 x/P 差分别8.04e-15、1.40e-13，共享修正复原绝对差1.49e-14，通过预定1e-9界限。76.75 s 的27537速度贡献为[0.060972,0.104461,0.147746] m/s，模长0.190941，其他点合计抵消一部分才得到总修正0.172563；78.90 s 的29636贡献模长0.112899，总修正0.111615。当帧五个新生点共享贡献近零，符合新生 P 零交叉块。该结论提升了“哪些点贡献当前校正”的证据，仍不是删点后的反事实，也未区分错误 bearing 与 LTV 路标估计偏差。独立审查另存，不将局部对齐宣称为任意输入正确性。

## 窗口 readiness 是否放行

R3B 两处 G/V-ready 都为 false。冻结286合同的离线 R3C shadow 也都为 false：76.20/78.55 s 的 P95 超过0.04 rad，清除窗口；重新锚定后，目标时刻分别只有0.50/0.30 s历史，不满足完整1 s再20事件确认。

**两个部分窗口的数值预算本身都通过。** 因而不能声称累计校正量识别了这两次不准确；此次未放行依赖先前异常后的等待。净校正小或抵消强都不是误差小的保证。0.252 m/s 是单点误差，不直接等同于违反 RMSE≤0.2 的全体统计验收。

独立 analysis293 按固定分母1806包、原连续性口径复核全域 shadow：G/V各385包、21.3178%、19.2500 s；ready 速度 RMSE/P95为0.052653/0.089186 m/s，重力角为0.831494/1.210061°，严重率0；但最长 joint-ready 仅3.05 s，未达到5 s。该结果既不支持当前候选通过，也不证明任意后续可靠输出。它是冻结轨迹上的离线策略检验，不是 C++ 在线验收。
