P95 正常不代表每点角度都小。例如 6.00 s 的 ID 4110 角为 0.17993 rad、v 修正率 1.31290；76.75 s 的 ID 27537 角为 **0.34921 rad**、v 修正率 **3.45124**；78.90 s 的 ID 29636 角为 0.16358 rad、v 修正率 2.23232。这些点均为既有点且在原 P95 总体内，单个最大值未成为 P95 排序统计量；并非被近中心规则排除。

不过两个窗口分别仍有 **2/6 与 15/23** 个 P95 正常但 v 修正率超限事件没有任何点角度超过 0.02。例如 79.30 s 最大角仅 0.011665 rad，v 修正率仍为 0.93444。因此不能把这些事件全部归因于单点大角，更不能凭同帧关联推导某点造成的共享状态修正。
