## 1. 为什么现在要做这件事

### 1.1 已有事实：保留成果，不从零重新研究

以下来自已提交报告与代码，而非本轮预想结果：[R1–R7]

| 已有证据 | 对本轮意味着什么 |
|---|---|
| 双目优先、历史几何回退的一次初始化已完成；新路径默认 OFF | 从现有实现修复，不重写另一个系统 |
| 两条 EuRoC 确认中 V-ready 速度 RMSE 约为 0.893→0.209、0.924→0.270 m/s；raw 也改善 | 已有实际收益必须作为回归资产保住 |
| 8/8 合成种子可靠性通过，但接受种子均来自历史几何分支 | 种子筛选不是全部问题；还需真实双目条件下的合成验证 |
| REGULAR、0.5 s 寿命中，种子等待约0.4 s，V-ready=0，raw速度误差约12.4/15.4 m/s | 必须处理“等到可靠时太晚”与共享状态恢复，不能只把阈值调严 |
| `LtvLandmarkManager::step()` 目前主要按入槽后时间累计 `mature_visible` | 特征驻留年龄不等于其信息已经稳定影响了共享 v/η |
| `LtvAdapter::frame()` 用 `enough_mature && snapshot.*_valid` 得到 ready | 必须独立验证 observer-level readiness，不能把数量门槛当误差保证 |
| 真实 UZH 确认 G/V-ready 参考支持仅约4.91/4.84 s | 区分实际可用性、参考缺失、两者时间交集，不追溯改历史NOT_MET |
| 冻结 live runner 仍有纳秒往返比较导致的管理日志遗漏 | 本轮必须真正修好新版本在线记录，不能继续靠恢复器作为正常交付流程 |
| 原主状态/P/FEJ/轨迹旁路已经通过 | 新改动必须持续维持该性质 |

### 1.2 本轮的核心问题

**一个种子的位置足够准确，不代表 observer 此刻的速度和重力也足够准确。** 它还可能进入一个已经偏离的共享状态；也可能只有很短的剩余观测；新旧点换入换出又会改变校正结构。这些是需要区分的假设，不是已证明的唯一原因。

本轮要把下面四层连接起来：

```text
种子几何可靠 → 能及时进入且持续观测 → 共享LTV状态形成有效估计
                                      → ready声明与实际误差相符
```

长期保持同一批点是可能的手段，不是唯一解法；不要求永远固定16个点。双目种子、适当历史、成熟点保留、启动/恢复组织都可以用于减少不必要的重新收敛。

**不可用场景可以不提供可融合输出，但不能把“所有时刻都不输出”称为成功，也不能在条件恢复后一直无法重新就绪。**

### 1.3 目标范围

主目标为 **EuRoC 类已标定双目＋IMU、使用原 OpenVINS 初始化和同一前端**的可用 Passive 模块。UZH 是扩展验证，继续保留已有不足结果；本轮不把某条 UZH 的参考缺失作为整个 EuRoC 工程无限停止的条件。

这个范围在新实验前冻结，不根据效果临时缩小。条件不满足、低激励、极短历史是必须验证的退化/恢复场景，不要求在信息不足时仍达到正常精度。

## 2. 成功到底是什么

### 2.1 三个必须同时成立的部分

1. **输出有用：** 在有有效参考的正常 EuRoC 输入上，G/V各自有足够就绪覆盖和绝对误差证据；不是仅相对很差的旧LTV降低若干百分比。
2. **使用安全：** 观测不足、时间异常、种子/状态不可信时，不把结果标为 ready；重新获得条件后可恢复；原始内部误差和不可用时间不被隐藏。
3. **Passive正确且可维护：** 主OpenVINS完全不受影响；真实日志完整、可复现、内存有界、能解释每次准入/退出/恢复原因。

这不是宣称已优于 OpenVINS，不是融合后 ATE 不退化证明，也不是统计一致性证明。两个 G/V 开关本轮始终 OFF。

### 2.2 必须区分的状态

推荐接口分开保存，名称可按本地代码调整：

```text
seed_valid                   种子是否满足几何准入
pool_ready                   当前集合是否有有效规模/分布/历史
observer_valid               状态、矩阵、时间和模型是否健康
ready_G / ready_V            当前是否允许作为潜在辅助输出
availability_state / reason  缺什么、正在恢复还是故障
raw_v / raw_eta               对应真实状态时刻的未经隐藏结果
```

不能只将 `min_features` 降低、`maturity_seconds` 置零，使覆盖变高就完成任务；也不能仅把原 `valid` 改名为 ready。

### 2.3 完成状态

- `PASSIVE_READY_EUROC`：第10节必需合同全部通过；限定为本轮工程环境，不夸大到任意运动。
- `PASSIVE_READY_EUROC_WITH_UZH_EVIDENCE`：在上一项基础上，额外获得满足支持要求的 UZH 证据。
- `NOT_ACHIEVED_WITH_EVIDENCE`：方法仍未满足目标，且允许的有效路径/轮次或预算已耗尽。必须保留可用部分与明确失败条件，不称成功。
- `BLOCKED_CORRECTNESS / BLOCKED_INPUT / BUDGET_EXHAUSTED`：无法推进的技术或资源阻断。

**有预算、有可检验的授权修正路径时，一个候选失败不是整个任务停止理由。** 反之，任务不能无限运行、擅自扩大资源或通过移动门槛达标。

## 3. 授权边界：哪些可以自主改，哪些不可以

### 3.1 保持不变

- 原 OpenVINS 状态定义、FEJ、IMU传播、MSCKF/SLAM视觉更新与原特征预算；不反向改变原特征数据库或地图深度。
- `StateHelper`、`Propagator`、`UpdaterMSCKF` 的数学实现；现有G/V融合公式不改且永不执行。
- 历史64次独立实验、上一轮冻结数据、原golden和历史验收结论。
- 相机/IMU原始数据、GT、已冻结的坐标/时间约定和评价器的物理定义。
- LTV连续动力学和Riccati模型默认不变，Q/V/P初值先保持C0；不继续做大范围增益或积分器搜索。

### 3.2 本轮可以自主修改

| 范围 | 可以做什么 | 所需证据 |
|---|---|---|
| `LtvFeatureHistory / Quality / Pipeline` | 质量组合、适当历史、种子选择、一次局部精化、实际双目或时序几何回退 | 几何/Jacobian/泄漏检查与种子质量回归 |
| `LtvLandmarkManager` | 有界候选池、成熟点保留、准入节奏、临时失踪、年龄定义、退出与复用规则 | ID/epoch/时序/交叉块保持测试 |
| 新 `LtvReadiness` 或适当合并 | 分别判断pool、observer和G/V；迟滞、冷却、恢复后确认 | 不能仅基于主VIO分歧或GT，需误差与覆盖评价 |
| `LtvAdapter` / 核心显式接口 | 原子启动/重建、候选预热、一次初始化事务、停止不可信输出 | 关闭旧行为一致、显式模式、端到端对照 |
| 日志/缓存/runner | 正式修复丢日志、记录整数事件身份、完整输入与状态证据 | 新live日志无需事后恢复即完整，数值路径一致 |
| 构建和最小只读桥接 | 明确取得原前端和已有位姿/协方差，不修改它们 | 主状态与原视觉处理旁路一致 |

允许调整质量、历史、成熟、健康状态机等工程参数；每轮改变一个主要机制，使用统一配置，记录前后差异。阈值不是逐序列参数，不允许读取序列名决定是否ready。

### 3.3 有条件的较深入修复

只有发现直接证据时，主agent可自行批准以下分支，并先做短小公式/等价测试，不必再次请用户确认：

- 一次入槽均值与共享状态不相容：比较更稳妥的启动时机、相干历史预热或原子重建，而非继续注入大量孤立种子。
- 单个observer不断被换入点扰动：最多比较一个活动observer＋一个预热observer；一次切换整份状态/矩阵/游标，不拼接两个observer的最优分量。
- 确认长期无有效几何导致内部失控：进入显式 `DORMANT/RECOVERING`，在恢复时重新初始化。不得把中止的旧状态冒充当前时刻的有效预测。
- 只有上述方案不能解决启动/恢复且证据支持时，允许独立模式比较**一次**读取当前只读OpenVINS状态初始化LTV的v/η；见第6.3节。禁止周期性复制，禁止把该模式声称为独立观测源。
- 数值实现中发现与既定公式不一致的可复现bug：允许最小等价修复并单独回归；不借机换成新滤波器或同时调增益。
- 新路标不确定度初始化若确需改变：先写清它是Riccati设计还是统计映射，再推导并独立验证；不把 `Sigma_seed` 生硬塞入 `P_L` 后声称概率正确。

更换完整后端、重新证明统一滤波器、引入回环/长期重识别/神经网络、运行G/V闭环不在授权范围。

## 4. 自主迭代方式与subagents

主agent全程负责目标、合同、运行账本、合并和下一步选择。允许最多3个subagents：

| 角色 | 任务 | 写入边界 |
|---|---|---|
| A：状态与生命周期 | 找到输出恶化的最早事件，设计启动/接替/恢复干预 | manager/readiness及专属单测 |
| B：几何与数据 | 双目/历史种子验证、不确定度、日志/输入支持审计 | seed/diagnostics专属文件 |
| C：独立验证 | 检查泄漏、P与坐标、旁路、统计分母、运行复现 | 独立测试与评审，不修改受测公式来让其通过 |

共享文件由主agent单独整合。独立worktree可用，但不强制搬迁工作区。最多2项重计算同时运行，包含完整回放、较大合成、批量几何、编译；所有代理共用账本和调度器。

每轮必有一页以内的决策记录：

```text
事实 → 假设 → 能区分该假设的最小干预 → 只改什么
→ 实测结果 → 保留/撤销/转下一分支 → 剩余预算
```

最多3轮机制级开发，每轮最多4个有记录的候选（总计≤12）；普通代码bug修复不机械算新候选，但完整运行计预算。未通过时自行调整授权路径，不回复“建议下次做XX”就停止。

当存在冲突指标，选能满足绝对可用性、覆盖、恢复与旁路合同的保守方案；数值上微小的非单调变化可报告，不把每个浮点量必须同时下降作为硬要求。不能改变第10节判定数字。

### 5.2 日志修复是本轮交付的一部分，不是选做

根据已保存的 `runner_logging_only.patch` 审核并在新版本实际修复。使用原始整数纳秒＋epoch＋单调事件序号关联日志；连续计算时间可以继续沿用已验证的double约定，不能因日志修复改变传播端点。

测试双精度无法无损表示大整数纳秒的样本。每个已消费图像包必须有唯一receipt，出生/写种子/退出/ready计数能从事件重建；新live日志与缓存重放诊断一致。关闭功能、只开日志的x/P/轨迹不变。

旧恢复结果仍是上一轮合法证据，旧缺陷不得追溯删除；但新版本不再依赖六次额外恢复才能交付完整结果。

### 5.3 不预设根因，先按事件找转折点

至少从已有 REGULAR 0.5 s失败、FAST 1 s正常以及真实EuRoC的启动/短断档各提取一个短窗口。缓存没有对应输入时只补最短必需捕获，不重跑旧矩阵。

分别记录：

| 时段/事件 | 要检查的量 |
|---|---|
| 第一个有效种子到来前 | LTV是否已经无约束积分很久；v/η/P如何变化；是否还在零重力初值附近 |
| 首次入槽/一次写入前后 | seed与当前点状态差、共享v/η是否变化、完整P是否按合同保留 |
| 每次相机校正 | `Δv、Δη`，旧/新路标的校正贡献，新增点比例与几何分布 |
| 活动点/成熟点不足时 | 是否仍盲目长时间积分、是否反复reset、是否过早ready |
| 退出、重新补齐后 | 输出是否恢复；为何恢复/为何未恢复；是否只因计数满足而放行 |

至少比较以下假设，不要求全部新增运行：H1未准备好就开始传播；H2可靠种子与已偏离的共享状态不一致；H3换点造成信息积累中断；H4 ready只看年龄/数量导致误报；H5等待/双目分支输入不足；H6日志/接口语义错误。

**先识别“误差何时开始增长、哪个干预能改变它”，不要直接把raw变大解释成深度seed不准，也不要只降低ready门槛。**

## 6. 建议解决路径：允许择优和回退，不强制全部实现

### 6.1 几何层：尽量及时，而非只收紧阈值

保留双目优先、历史回退的已有成果。先检查同一physical timestamp、相机外参和双目ID关联；不将异步右目观测强行当作同步。

对历史种子，合理利用仍有效的历史视差与联合位姿P；有必要时比较一次角度/逆深度精化，但不能在主OpenVINS优化器中增加新因子。机会分母在最终风险Gate前定义。

观察到近退化或偏短距离时，可以等更多历史或切换到已有双目来源；不允许拿主VIO的当前v/g作为“深度真值”。世界点回机体系必须在真正写入时刻完成。

必须覆盖双目分支的合成输入，而非再次让所有确认都落到历史回退。至少测试同步双目、时序单目、双目暂时消失、错误匹配/时间错误负样本；不要求坏输入也有高接受率。

### 6.2 集合层：候选、活动和可用集合分开

建议沿用并完善现有模块，不机械新增大量类：

```text
CANDIDATE → SEED_READY → ACTIVE/WARMING → MATURE
                                    ↘ COASTING → RETIRED
```

关键要求：

- 保留可靠旧点；新点不能仅因图像位置更均匀就赶走成熟点。
- 同一ID入槽与一次写入为原子事务：发生于该点第一次校正之前；无重复ID、时间错误或被拒绝后半完成写入。
- 成熟判据不能只有 `time-entered`。允许结合实际有效校正次数、持续可见、几何证据、预测到新观测的误差和共享状态稳定性。
- 不把不同ID拼成同一物理点，不用未来寿命选点；失踪只传播，不重复旧bearing。
- 既有候选/TTL/tombstone/ID映射需要有界内存策略；清理不能让真实旧ID被误当成新ID并重复seed。完整历史可写入日志而非无限保留内存。
- 若容量/最低点数需修改，先把“调低最低点数”作为单独对照；必须用输出合同证明有效，不能以旧硬编码被绕过作为成功。

### 6.3 共享observer层：可靠启动、有限失效、正确恢复

推荐状态机（语义必须具备，具体名称和实现可简化）：

```text
COLD/COLLECTING → BOOTSTRAPPING → TRACKING
                         ↑          ↓
                         └ RECOVERING ← DEGRADED/COASTING
                                            ↓
                                         DORMANT
```

- **COLLECTING**：积累候选；没有可靠活动集合时不必让一个已知未初始化的observer无限裸积分。时间与缓存仍正确维护，不造当前v/g输出。
- **BOOTSTRAPPING**：从一个明确起点初始化或因果预热；保存状态/矩阵/时间/身份来源。不能先把错误积分历史当作可靠后验。
- **TRACKING**：正常递推；G/V就绪各自判断，输出来自同一份持久observer状态。
- **DEGRADED/COASTING**：短缺测可有限传播但下调或关闭ready；恢复要确认信息和状态，不是点数一补齐就立即放行。
- **DORMANT**：超过确定的无信息/状态健康界限后停止声明当前有效估计。最后可靠值可存档，但不得带当前时间戳发布为新测量。
- **RECOVERING**：候选与条件恢复后自动重建/预热并回到正常状态，不要求人工reset，不把整个OpenVINS一起reset。

这是受观测条件限制的输出契约，不是要求每次短暂掉点都清空全部状态。优先保留短暂缺测的历史；强制reset必须有原因、冷却和速率限制，禁止reset风暴。

**优先比较的最小方案：**延迟启动或使用真实过去输入预热；恢复前保留足够有效历史；将过量新点隔离在候选中；必要时一个活动＋一个预热observer。不能把历史bearing直接投到当前状态，不可使用未来帧。

**一次性主VIO辅助启动为条件分支，不是默认捷径：**如果最小干预证明零v/η冷启动或恢复是主要瓶颈，可比较在明确的首次启动/恢复事务中设置

`v_B = R_WBᵀ v_W`，`η = R_WBᵀ g_W`，

其中输入只能是当时可用的只读OpenVINS估计、固定物理g；绝非GT。该模式命名 `POSE_AIDED_BOOTSTRAP`，单独消融，来源和每次写入全部审计。每个episode最多一次v/η写入，禁止相机频率复制、定时刷新或为了误差小反复重启。几何不足时留在DORMANT，不通过每次重置把结果拉回主估计器。两次质量触发的辅助bootstrap至少相隔预冻结的30秒；真正输入中断另记故障，不用故障重置规避。最终另报离辅助写入5秒以后的ready精度/覆盖，并至少有一个≥20秒无v/η外部重写的有效运行段。

这是显式允许的新对照，扩大了上一版“只写路标、不写v/η”的正常边界；如果采用，必须说明得到的是主VIO辅助初始化的observer，不能用其贴近OpenVINS当成独立信息增益。优先不采用，不能仅为通过数值门槛绕过本体问题。

### 6.4 Readiness层：不把“种子合格”当作“当前运动状态正确”

在集合指标外，至少评估：时间一致性、状态数值、重力方向可定义、当前可靠点实际观测、预测角度一致性、种子更新/校正后瞬态、状态修正率和异常种子比例。相关阈值由开发数据校准，必须在确认前固定。

允许G和V不同门槛及不同恢复时间，但同时给出joint-ready；不能在最终统计时发现交集误差较小，就事后只报告交集。

与OpenVINS的分歧可作为诊断/辅助异常证据，不能作为唯一ready条件，更不能把“接近OpenVINS”直接定义为正确。G方向与η模长分开；后续用途是方向观测，本轮仍完整记录模长，不靠强行归一化隐藏状态错误。

## 7. 数学、协方差与一次初始化的不可越界合同

继续区分：`P_E`为只读主滤波协方差；`P_L`为observer Riccati设计矩阵；`Sigma_seed`为近似几何不确定度/风险。三者不能因为维度一样就互换。

1. 默认保持已验证LTV动力学、Riccati与C0参数。新点均值写入后，原有状态及对应P交叉块必须按明确索引保留；旧路径不受新功能影响。
2. 一次均值写入是初始化操作，不自动等于一次有统计意义的Kalman测量更新；也不证明旧P正确描述种子误差。不要为追求“平滑”私自多次重复写入同一种子。
3. 若使用状态重参数化或相干bootstrap，重新推导相应坐标/局部Jacobian；保留同一pose在不同输入中的相关性，不重复当作独立误差。PSD或奇异P_E使用已有秩处理，不能无条件加对角量。
4. 主状态—bearing、跨种子和几何来源的相关性未全部建模；风险得分不等于已校准概率。不得新增“95%置信”标签而无校准。
5. 任意等价坐标变换下机体系种子和运动结果应一致；检查右/左扰动、重力符号、光轴深度与射线距离区别。
6. 独立数值Jacobian以实际retraction验证；参考应使用独立计算，而非同一函数相互调用。混合单位完整状态范数不得被当作米制误差。
7. 数学/数组/时序错误先修，不能以小权重、关闭FEJ、截断主P谱或放宽测试阈值掩盖。

## 8. 实验安排：先便宜诊断，再真实链路，自动循环

### 8.1 复用与数据身份

从manifest查找实际缓存与运行，不猜文件名。缓存只有在包含本轮所需的**全部**候选bearing、姿态/P、IMU及时间上下文时可复用；只保存旧选择结果的缓存不能检验新的选择器。新增缺失字段需捕获真实原输入，不凭空恢复未知量。

主OpenVINS不受LTV影响时，可一次读入原输入同时运行P_PREV/P_NEW，减少重复前端工作；仍分别计量两个observer耗时，并至少用独立单运行确认并行比较器不改变数值或时序。改变了主输入捕获结构后重做缓存等价。

### 8.2 开发集

- 合成：沿用REGULAR/FAST历史失败与成功条件作回归；新增匹配实际双目基线/标定的合成输入；添加可恢复的观测不足段。
- 真实开发：`V1_01_easy、V2_02_medium、V2_03_difficult`。这些已经在历史研究出现，明确当作开发/回归，不再称全新独立测试。
- 当前 `indoor_forward_3/6` 只作扩展开发或不足证据审计，不反复换GT支持来凑通过。

首先用一个短窗口验证因果变化，再跑对应完整缓存，候选稳定后才跑完整VIO。

### 8.3 必须包含的合成行为测试

| 类型 | 输入条件 | 应验证什么 |
|---|---|---|
| 正常双目 | 当前双目可形成可靠初值，0.5/1 s轨迹，REGULAR/FAST | 双目分支真实被调用，精度与及时性，不重复只测历史回退 |

| 坏种子 | 有固定比例错误匹配、距离离群值、少量重尾扰动 | 不以大校正污染共享状态或误报ready |
| 有限缺测 | 由输入预先定义：正常15 s→无/弱几何15 s→恢复30 s | 及时不可用、无reset风暴、条件恢复后真实重获准确状态 |
| 长时资源 | 有界输入重复/固定场景持续至少10分钟，方法不看脚本阶段 | 内存、候选/ID管理有界，无时间累计错误；不当作新独立精度样本 |

输入阶段标签、未来可见时长、真值ID/几何/运动只允许在生成器与评价器；估计器看不到它们。

在合成中需要模型丰富性：两种噪声seed、至少一种时间相关的位姿误差，不只独立各帧微扰；同一pose噪声对不同特征共享。参数候选不能换成更小噪声来通过。

确认用的随机seed在最终候选确定前不可读取标签；建议预注册201/202等与历史开发不同的seed。随机seed变化仍然只是同类合成确认，不宣称独立实景泛化。

### 8.4 真实最终验收

主目标覆盖 **EuRoC全部11序列** 的B/P_PREV/P_NEW运行与审计。已有相同主版本/配置/输入/数值身份的有效B或P_PREV可复用；否则重跑。至少全部P_NEW在真实runner中完成，不能只用Python缓存结果替代交付。

### 8.5 UZH扩展不再成为无界阻断

保留 `indoor_forward_6` 旧结果。先使用输入时间与GT有效区间做元数据审计，区分总GT支持和ready交集；不得按新LTV的误差选序列。

### 8.6 冻结与失败后的自主执行

为了兼顾工程迭代与证据可信，区分：

- **开发/回归：** 可以反复检查已知序列并修正候选，明确不是独立泛化证据。
- **候选版本冻结：** 同一轮正式表格只来自同一个版本和配置，运行中不得原地改参数。
- **最终确认：** 使用新合成seed、实际runner及完整证据；不按最终误差微调每序列阈值。

### 10.1 必须通过：非侵入、数据与记录

### 10.2 正常EuRoC条件下的输出合同

| 指标 | 主目标 |

| ready覆盖 | 在所有B与参考有效的EuRoC序列，每个分支≥20%的初始化后相机包，且有效参考交集各≥10 s |

相同方法的raw、ready_G、ready_V、joint-ready四种支持均输出；OLD/NEW/OpenVINS在每列使用相同时间支持。G方向改善与η向量改善分开解释。要求的是本轮参考下的误差，而不是自动证明真实世界全状态最优。

### 10.3 种子质量与供给合同

合成中单独报告STEREO和TEMPORAL来源，不能让双目分支完全不被执行。可靠种子仍定义为正确ID、正ray、相对三维误差≤10%，并另报5%档。正常、可产生初始化机会的各确认条件，可靠比例≥90%、机会接受率≥20%、每类来源至少100个接受样本。

机会在最终风险Gate前定义；双目机会与历史机会分开，以全部合法候选和全部birth作附加分母。坏匹配或无视差负对照不要求20%接受率，要求合理拒绝且记录原因；哪些属于负对照由输入条件预先规定，不能看输出坏了才改类别。

### 10.4 退化与恢复合同，不要求凭空估计

- 原REGULAR 0.5 s案例完整保留为压力回归。允许在没有有效几何时不ready，但不能再次把12–15 m/s的错误状态当作可用输出；原始误差照实记录。
- 在预定义“正常→不足→恢复”合成输入中，输入端确定的断流/非法时间/空观测应在最多2个相机包内撤销对应ready；仅仅误差变化并不是在线可见信号，不能用GT触发。
- 在没有足够信息的区间，不要求raw误差与充分可观测情况同样小；但必须数值有界/有明确DORMANT行为，不无限积累错误却假装健康，不能反复主VIO复制。所有不可用和重建时间计入覆盖。
- 当输入恢复后，固定几何供给评价器标注的“连续足够可靠观测开始”只用于计时：10秒内至少出现一个持续5秒、真实满足宽档(v≤0.10 m/s，G方向≤1°，模长误差≤0.20 m/s²)的就绪区间。估计器不得读取该标签。未恢复就列为恢复失败，不把episode无限拆短。
- 合成与可靠真实参考中同时记录严重错误ready占比：v误差>1 m/s或G方向>5°的ready样本比例，每个对应分支≤1%；不凭单个总RMSE掩盖错误放行。
- 相同观测不足不能产生reset风暴。质量触发bootstrap/全量重建的最小间隔及每次原因必须预登记；默认30秒，物理输入故障重置分开统计，不能伪造故障。

纯观察不可能保证所有未建模噪声下零错误。上述是有限验证目标，不是绝对安全承诺。若不具备恢复所需信息，应明确报告范围限制，不强行生成输出。

### 10.5 运行与复现

最终新配置在真实runner完整执行，至少两条代表序列P_NEW复测，主状态及方法事件/输出在同机确定性模式下一致。日志开启/关闭不改变数值；计时分离估计计算、缓存和重诊断。

在同一受控计算环境，轻量诊断关闭时，LTV支路完整相机事件均值应小于一个相机周期、P95不超过两个周期；当前20 Hz相机对应约50/100 ms。本轮不声称硬实时；若超过则独立记录性能NOT_MET，优先精简已有重计算而非更换算法后端。长时测试内存受声明容量限制，不逐帧线性增长。

## 11. 新预算和持续执行边界

不是沿用旧36/36或64/64，本文件授权一个新的有界工程任务：

| 项目 | 新上限 | 预留原则 |
|---|---:|---|
| 完整合成observer运行 | 80 | 至少24次留给新seed、双目/历史、失败恢复和复测 |
| 完整真实VIO或完整缓存LTV执行 | 72 | 至少40次留给11序列B/P_PREV/P_NEW及复测；实际可复用的运行可减少，不必耗满 |
| 真实短段≤10秒 | 24 | 调试/旁路；不拼接逃避完整运行计数 |
| 小几何/局部Monte Carlo重求解 | 30000 | 仅确实用于可靠性校准，不包装完整observer运行 |
| 完整候选 | 12 | 最多3轮机制开发，不做笛卡尔积 |
| 子代理 / 重计算并发 | 3 / 2 | 共用锁和账本，短测也占计算槽 |

一次完整主回放同时跑多个只读observer可记一次输入遍历，但记录observer数量、CPU和总工作量；同一缓存再次完整跑新的observer仍计一次。日志恢复是实际重放就计数。失败和重试不退款，不以换目录或换agent重置预算。

每完成一轮重新检查“剩余预算是否足够最终验收”。不足时优先停止低价值候选，保住交付验证，不在72次耗尽后才发现无正式确认。

额度、权限或机器中断时保存checkpoint、已确认产物、活动PID、预算与精确恢复命令；`/goal resume`可继续同一任务，不能从头重复。不得购买额度、升级或自动使用此前另一个任务授权过的重置卡；需要账户操作时只请求必要操作。
