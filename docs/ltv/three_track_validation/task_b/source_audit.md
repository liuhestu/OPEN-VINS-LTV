Strong geometry uses camera 0 historical bearings strictly before `ctx.time`; its last input is approximately one camera interval earlier. It uses the same historical state window and point identity. Current tracker matching is an unavoidable source of identity contamination; no independent physical-point identity truth exists.

Historical counterexamples constrain the next experiment: immature points and short anchors do worse than weak anchor propagation. Against strong historical geometry, the V2_03 normal point estimate is worse, and all mature sequence confidence intervals include zero. Startup and recovery tails must remain visible. Weak anchor advantages cannot establish useful independent information.

Three bounded causal candidates are proposed before their gate results: B0 prior maturity and ready V; B1 additionally 0.2–0.5 s anchor span; B2 additionally relative 3D disagreement at most 0.02. Disagreement is computed from the two predictions before consuming the current bearing: `norm(ltv_point-main_point)/max(norm(main_point),0.1m)`. It is dimensionless, not a bearing error or a statistically calibrated innovation. This tests whether agreement excludes risky geometry while maintaining useful predictive supply. It may remove valuable corrections, so coverage and common-support advantages are required.

The shared sources are not independent: seed uses main historical poses and bearings; Observer shares calibrated/bias-corrected IMU and historical camera information; main MSCKF consumes related visual observations. Unknown cross blocks have not been proved zero. `P_Riccati` is not true landmark covariance. Full correlation closure is deliberately not the engineering ON admission blocker in this round; frozen predictive quality is.
