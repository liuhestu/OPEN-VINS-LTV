# B3 engineering approximation: implementation and validation scope

Status: **implemented; registered native checks and 40s OFF parity passed; complete engineering qualification pending**. The first true native L_ON command exited 0; actual application, contribution and state/P difference will be audited after the shared performance window. No main-estimate benefit or statistical calibration is claimed from that exit code.

B3 is selected under the explicit user engineering-admission amendment. The original ≥5% predictive-benefit criterion remains FAIL for V2_03. B3/B4 both passed original risk/coverage; B3 has 36.77% V2_03 mature supply versus 21.44% for B4, avoids B4's online strong-geometry fitting, and B4 does not raise measured gain. These observations justify the engineering experiment while leaving the prediction conclusion intact.

The new native updater freezes the current point after IMU propagation before current camera processing. Anchor points are saved after camera correction, from the oldest live same-epoch/global-ID/core-ID/entered-generation snapshot. The source coordinate is physical IMU meters, matching native current IMU pose and past clone. Geometry uses current means; its Jacobian uses native FEJ means when enabled. Native JPL injection signs and all four direct rotation/position blocks are checked via real PoseJPL.update, with current/FEJ separation and common-world SE(3) gauge invariance. Maximum finite-difference error is 3.55e-8 for eps=1e-7, within the preregistered 1e-6 bound.

The independent enable_landmark_approx flag defaults false. G/V remain OFF in this line, max_slam=0, and confirmation20 is retained. Existing visual observations are kept. A single frozen native prior, one consumed receipt and one visual-plus-landmark EKF call perform the approximate update. Current unavailable/invalid Observer transactions, changed identity/epoch, absent live clone and invalid numerical blocks are not submitted.

R_approx is isotropic in m²: sigma=(0.5 m+0.02×norm(point) m), variance=sigma²×(1+age/0.55 s). At most two ascending-identity points per frame are selected. Before forming K, variance increases until trace(H P_native Hᵀ)/variance≤0.005 per point, ≤0.01 per frame. K*r is never truncated. These are declared engineering choices, not calibrated covariance, statistical confidence or a proof that unknown correlation is harmless.

Unknown main/seed/Observer/anchor/cross-point/shared-IMU/bias/visual blocks are omitted under the approximation. They have not been proved zero. P_Riccati is not used as true landmark error covariance. Native stored P is also subject to the existing covariance-chart reset limitation identified by C. Numeric PSD and deterministic equality do not close these model gaps; EuRoC supplies no independent landmark truth here.

The updater logs each candidate identity, old anchor time, age, relative disagreement, rejection/selection, variance in m², information before/after the budget and residual components in m. The frame log records receipt consumption, joint_applied, landmark rows, actual K_L*r_L component norm and gyro/accelerometer-bias components. The full error-state norm mixes radians/meters/bias units; it is an action diagnostic, not a position-accuracy metric. Main trajectory/state/P evidence is kept separately.
